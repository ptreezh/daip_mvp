**执行流程回顾 (适用于每个任务):**
1.  **研究 (Research):** 深入理解任务背景、现有代码、相关 API 和项目约定。
2.  **创意 (Ideate/Create):** 构思解决方案，探索不同实现路径，考虑最佳实践。
3.  **计划 (Plan):** 制定详细、具体的实施计划，明确 TDD (红-绿-重构) 循环中的每一步。
4.  **细分 (Refine/Subdivide):** 如果任务复杂，进一步细分为更小、更易于管理和验证的子任务。
5.  **实施 (Implement):** 按照计划执行代码修改、测试等操作。
