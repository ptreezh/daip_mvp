## 🚀 项目概览

### 核心概念
`daip-cli` 是DAIP-LIVE系统的官方统一命令行界面。它旨在为开发者、高级用户和自动化脚本提供一个功能强大、执行高效、稳定可靠的统一入口，整合了过去所有CLI原型和Web端的核心场景能力。

### 关键特性
- ✅ **统一入口**: 废弃并整合 `interactive_cli.py`，成为唯一的CLI。
- ✅ **功能对齐**: 需求规格向Web交互端看齐，覆盖核心用户场景。
- ✅ **专业体验**: 基于 `Typer` 构建，提供强大的参数验证、帮助信息和错误处理。
- ✅ **可扩展架构**: 清晰的模块化设计，便于未来新增命令和功能。
- ✅ **TDD驱动**: 所有功能开发均由测试用例驱动，保证代码质量。

---

## 🎯 核心目标

### 用户目标
- **开发者/高级用户**: 提供一个高效、可预测、文档齐全的命令行工具，以最快速度完成任务。
- **系统管理员/自动化**: 提供一个稳定、可编写脚本的接口，用于系统集成和自动化运维。

### 技术目标
- **代码质量**: 遵循TDD原则，实现高测试覆盖率。
- **可维护性**: 结构清晰，易于理解、修改和扩展。
- **性能**: 命令执行响应迅速，资源占用合理。
- **一致性**: 命令设计风格和用户体验保持高度一致。

### 第1阶段: 基础与助手 (Foundation & Assistant MVP)

    - [ ] 为现有 `start`, `status`, `roles` 命令编写TDD测试用例。

    - [ ] 建立完整的需求和架构文档。

### 第2阶段: 场景对齐与核心功能 (Scenario Alignment & Core Features)
