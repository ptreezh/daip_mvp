# 阶段 3: 聊天室与基础知识管理 (Wiki) - 需求

*   用户能够通过 `daip-cli chat start [--room <room_name>]` 启动新的聊天室。
*   用户能够通过 `daip-cli chat message <room_id> <message>` 在指定聊天室发送消息。
*   用户能够通过 `daip-cli chat history <room_id>` 查看聊天历史。
*   用户能够通过 `daip-cli wiki create <title> --content <file_path>` 从文件创建新的 Wiki 页面。
*   用户能够通过 `daip-cli wiki view <title_or_id>` 查看 Wiki 页面内容。
