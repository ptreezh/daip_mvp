# 基于角色的Wiki协作系统 - 重构后的愿景

## 概述
本系统旨在构建一个由用户发起、AI虚拟角色协同参与的知识协作生态系统，其中多个AI角色能够在用户发起的wiki协作任务中，基于各自的专业知识和认知能力，协同完成词条的创建、编辑和维护。

## 核心理念
1. **用户发起，系统协调**：用户发起wiki协作任务，系统负责协调角色参与
2. **角色专业驱动**：每个AI角色基于其专业知识和认知能力参与知识管理过程
3. **协同决策**：通过多角色协作和系统协调达成共识，确保知识质量
4. **用户监督**：用户作为任务发起者和最终仲裁者，全程监督协作过程

## 工作流程
1. **用户发起协作**：用户发起wiki编辑任务或系统检测到内容变更需求
2. **系统指派角色**：系统根据内容领域自动指派相关专家角色
3. **角色协同工作**：
   - 角色A创建初始提案
   - 角色B、C作为评审者参与评审
   - 角色D作为协调者促进讨论
4. **系统协调决策**：系统收集各角色意见，协调达成共识
5. **用户确认**：用户最终确认更新结果
6. **知识更新**：自动执行批准的变更

## 关键差异
与之前设计的主要区别：
- 角色不能主动发起任务，只能被动参与
- 用户是任务的发起者和最终决策者
- 系统承担更多的协调和指派职责
- 角色的专业知识是协作的核心驱动力
