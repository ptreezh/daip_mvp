# DAIP-LIVE 自主执行主计划

**创建日期**: 2026-08-07
**执行模式**: 全自动长时运行 (autonomous loop)
**安全机制**: worktree 隔离 + grill-down 验证 + TDD 门禁

---

## 🎯 总体目标

将 DAIP-LIVE 从当前状态 (35/100 NOT READY) 提升至生产就绪状态 (90+/100)，无需人工干预。

**时间估算**: 4-6 周（全自动执行）

---

## 📋 执行原则

| 原则 | 实施 |
|------|------|
| **TDD 驱动** | 每个功能先写测试 → 红灯 → 实现 → 绿灯 → 重构 |
| **YAGNI** | 只实现当前阶段必需的功能，不做过度设计 |
| **KISS** | 保持简单，优先选择最直接的解决方案 |
| **SOLID** | 接口隔离、依赖注入、单一职责 |
| **Spec 先行** | 每个 Phase 必须有完整的 SPEC.md 文档 |
| **Worktree 隔离** | 每个 Phase 在独立 worktree 中执行 |
| **Grill-down** | 每个任务执行前必须经过方案验证 |
| **原子提交** | 每个修复一个提交，提交信息规范化 |

## 🔄 执行流程

```
┌─────────────────────────────────────────────────────────────┐
│                    自主执行循环                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. LOOP 启动 → 检查当前进度                                  │
│       ↓                                                     │
│  2. 读取当前 Phase SPEC.md                                   │
│       ↓                                                     │
│  3. 创建 worktree (phase-N)                                 │
│       ↓                                                     │
│  4. GRILL-DOWN 验证方案                                      │
│       - 分析影响范围                                         │
│       - 验证测试策略                                         │
│       - 确认回滚方案                                         │
│       ↓                                                     │
│  5. TDD 执行                                                │
│       - 写测试 (红灯)                                        │
│       - 实现修复 (绿灯)                                       │
│       - 重构 (改善)                                           │
│       ↓                                                     │
│  6. 验证 (pytest + mypy + ruff)                             │
│       ↓                                                     │
│  7. 原子提交到 worktree                                      │
│       ↓                                                     │
│  8. 合并到主分支                                             │
│       ↓                                                     │
│  9. 更新进度 → 回到步骤 1                                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 🔧 工具配置

### Worktree 命令
```bash
# 创建 phase worktree
git worktree add .git-worktrees/phase-0 -b phase-0

# 删除 phase worktree
git worktree remove .git-worktrees/phase-0

# 列出 worktrees
git worktree list
```

### Loop 配置
```bash
# 启动自主循环
/loop 30m /autonomous-daip-run

# 或使用 cron
0 * * * * /autonomous-daip-status-check
```

## 🚨 中断与恢复

### 中断条件
- pytest 失败超过 3 次
- mypy 错误无法自动修复
- worktree 合并冲突
- 磁盘空间不足

### 恢复流程
1. 检查 `.planning/autonomous_plan/STATE.md`
2. 读取失败 Phase 的 PROGRESS.md
3. 手动审查后恢复
