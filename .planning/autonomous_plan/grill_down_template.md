# Grill-Down 验证模板

**用途**: 每个任务执行前必须经过 Grill-Down 验证

---

## 🔍 Grill-Down 流程

```
┌─────────────────────────────────────────────────────────────┐
│                     Grill-Down 验证                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 问题分析 (Problem Analysis)                              │
│     - 根本原因是什么？                                       │
│     - 影响范围多大？                                         │
│     - 有什么副作用？                                         │
│                                                             │
│  2. 方案设计 (Solution Design)                               │
│     - 最小修改是什么？                                       │
│     - 是否符合 YAGNI/KISS/SOLID？                            │
│     - 有无更好的替代方案？                                   │
│                                                             │
│  3. 测试策略 (Test Strategy)                                 │
│     - 测试覆盖什么场景？                                     │
│     - 边界条件是什么？                                       │
│     - 如何验证修复有效？                                     │
│                                                             │
│  4. 回滚方案 (Rollback Plan)                                 │
│     - 如果修复失败如何回滚？                                 │
│     - worktree 如何清理？                                    │
│                                                             │
│  5. 执行验证 (Execution Validation)                          │
│     - TDD 红灯 → 绿灯                                       │
│     - 所有测试通过                                           │
│     - 无回归                                                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
