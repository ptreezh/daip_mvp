# DAIP-LIVE 文档库系统

一个完整的文档索引和浏览系统，让所有989个文档都能在线访问。

## 📊 系统统计

- **总文档数**: 988个
- **总大小**: 6.4 MB
- **文档分类**: 11个主要分类
- **覆盖范围**: 整个DAIP-LIVE项目

## 🚀 快速开始

### 方法1：使用批处理文件（Windows）
```bash
# 双击运行
start_server.bat
```

### 方法2：使用Python脚本
```bash
# 使用默认端口8000
python start_document_server.py

# 使用自定义端口
python start_document_server.py --port 8080

# 不自动打开浏览器
python start_document_server.py --no-browser
```

### 方法3：手动启动
```bash
# 在文档目录运行
python -m http.server 8000

# 然后访问
http://localhost:8000/document_library.html
```

## 🎯 功能特性

### 搜索功能
- **全文搜索**: 支持标题、内容、路径的模糊搜索

## 🛠️ 故障排除

### 常见问题

**Q: 无法启动服务器？**
A: 检查Python是否正确安装，运行 `python --version` 测试

**Q: 端口被占用？**
A: 使用其他端口 `python start_document_server.py --port 8080`

**Q: 文档无法打开？**
A: 确保文档路径正确，检查文件是否存在

**Q: 搜索没有结果？**
A: 检查搜索关键词，尝试使用更通用的词汇
