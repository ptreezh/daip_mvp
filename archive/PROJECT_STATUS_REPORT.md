## 🏗️ 系统架构

### 技术栈
- **后端框架**: FastAPI 0.110.0
- **前端界面**: Streamlit + 自定义组件
- **数据库**: ChromaDB (向量存储) + SQLite
- **LLM集成**: Ollama (llama3:instruct, nomic-embed-text)
- **开发工具**: Poetry, pytest, ruff, mypy

### 架构层次
```
应用层 (FastAPI + Web界面)
    ↓
协议层 (工作流引擎 + 辩论协议)
    ↓  
核心服务 (角色管理 + 记忆服务 + Wiki服务)
    ↓
内核层 (LLM接口 + 工具执行器 + 上下文分段器)
```

### 服务组件
- **角色管理器**: 131个专业角色，智能匹配算法
- **记忆服务**: 短期/长期记忆，上下文管理
- **Wiki服务**: 版本控制，协作编辑
- **合成引擎**: 多智能体讨论结构化共识
- **任务管理器**: 协作任务分解和跟踪
- **Forum服务**: 多智能体辩论编排和共识跟踪
- **辩论编排器**: 实时辩论流程管理
- **用户干预管理器**: 智能输入优化和集成
