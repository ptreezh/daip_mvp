### 环境要求

- Python 3.12+
- 异步运行时支持
- 64MB+ 可用内存

### 基本使用

```python
import asyncio
from src.debate_system import DebateStateManager
from src.real_demo_system.multi_role_debate_system import MultiRoleDebateSystem

async def main():
    # 创建辩论系统
    state_manager = DebateStateManager()
    debate_system = MultiRoleDebateSystem(llm_integrator, role_manager)
    
    # 启动辩论
    result = await debate_system.start_debate(
        debate_topic="AI在教育中的应用",
        participating_roles=["expert1", "expert2"]
    )
    
    print(f"辩论已启动: {result['debate_id']}")

asyncio.run(main())
```
