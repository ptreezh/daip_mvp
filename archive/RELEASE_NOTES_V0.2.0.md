# DAIP-LIVE V0.2.0 正式版发布说明

## 🎉 版本概述

DAIP-LIVE V0.2.0 "场景增强版" 正式发布！这是一个重要的功能更新版本，引入了三大核心场景系统，为用户提供专业的智能协作体验。

**发布日期**: 2025-08-03  
**版本代号**: Scenario Enhancement (场景增强版)  
**分支**: feature/v0.2-scenario-enhancement → main

## 🚀 使用方式

### Web界面体验
```bash
# 启动V0.2 Web演示
python integrated_web_demo.py

# 访问地址
http://localhost:8000
```

### CLI使用
```bash
# 智能场景推荐
daip-cli chat "AI在教育中的应用研究"

# 指定场景
daip-cli scenario academic "深度学习发展趋势"
daip-cli scenario expert "是否采用微服务架构"
daip-cli scenario casual "推荐好电影"
```

### API集成
```python
from src.scenarios.scenario_manager import ScenarioManager

manager = ScenarioManager()
result = await manager.smart_chat("用户输入", user_id="user123")
```
