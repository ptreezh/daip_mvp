# TUI完整体验用户手册

## 简介

本文档介绍了如何体验DAIP-LIVE系统的完整TUI（文本用户界面）功能。TUI提供了丰富的交互功能，包括快捷命令、会话管理、角色管理、知识库查询、辩论系统等。

## 先决条件

确保已安装所有依赖：
```bash
poetry install
```

## 启动TUI界面

要启动完整的TUI体验，需要运行主程序。由于当前项目结构中没有直接的TUI启动脚本，我们需要创建一个简单的启动脚本：

```bash
poetry run python -c "
import asyncio
from src.daip_live.tui import DAIP_TUI
from daip_live.agent_engine.executor import AgentExecutor

async def main():
    # 创建一个简单的executor（实际使用中会更复杂）
    executor = AgentExecutor()
    app = DAIP_TUI(executor, '欢迎使用DAIP-LIVE TUI系统')
    await app.run_async()

if __name__ == '__main__':
    asyncio.run(main())
"
```

或者创建一个启动脚本文件：

```bash
# 创建tui_runner.py文件
echo "
import asyncio
import sys
import os
sys.path.insert(0, os.path.join(os.path.dirname(__file__), 'src'))

from daip_live.tui import DAIP_TUI
from daip_live.agent_engine.executor import AgentExecutor

async def main():
    # 创建一个简单的executor（实际使用中会更复杂）
    executor = AgentExecutor()
    app = DAIP_TUI(executor, '欢迎使用DAIP-LIVE TUI系统')
    await app.run_async()

if __name__ == '__main__':
    asyncio.run(main())
" > tui_runner.py

# 运行TUI
poetry run python tui_runner.py
```

## TUI快捷命令体验

在TUI界面中，可以使用以下快捷命令：

### 个人助理命令
- `/pa <goal>` - 启动个人助理会话，例如：`/pa 帮我写一份项目计划书`

### 角色管理命令
- `/role add <name> <persona>` - 创建新角色，例如：`/role add 项目经理 负责项目管理的专业人员`
- `/role view <role_name>` - 查看角色详情，例如：`/role view 项目经理`
- `/role list` - 列出所有角色

### 知识库命令
- `/0 [query]` - 搜索知识库，例如：`/0 项目管理方法`
- `/0` - 同步知识库（无参数时）

### 辩论系统命令
- `/debate <topic>` - 启动辩论会话，例如：`/debate 远程办公的优缺点`

### 会话管理命令
- `/v [query]` - 搜索会话，例如：`/v 项目计划`
- `/l` - 列出所有会话历史
- `/c` - 中止当前会话
- `/g` - 继续当前会话
- `/p` - 暂停当前会话
- `/t` - 显示会话树结构
- `/tc <index>` - 中止当前会话并跳转到指定会话，例如：`/tc 1`
- `/tt <index>` - 暂停当前会话并跳转到指定会话，例如：`/tt 1`

### 焦点切换
- `Ctrl+Tab` - 在输入框和输出区域间切换焦点
- `Ctrl+A` - 在输出模式下全选文本
- `Ctrl+C` - 在输出模式下复制选中文本
- `ESC` - 退出输出模式或中止所有会话

## TUI界面功能

### 主要组件
1. **输出区域**：显示系统响应、工具调用结果、代理思考过程等
2. **输入框**：用于输入命令或与系统交互
3. **状态栏**：显示当前模型信息、Token使用率、系统状态等

### 状态栏信息
- **模型信息**：显示当前使用的模型名称
- **Token使用率**：显示上下文使用情况，不同使用率会以不同颜色显示
- **系统状态**：显示当前系统状态（空闲、思考中、执行工具等）
- **焦点模式**：显示当前焦点在输入框还是输出区域

## 交互体验流程

### 1. 启动系统
启动TUI后，系统会显示欢迎信息和使用提示。

### 2. 使用快捷命令
可以使用各种快捷命令与系统交互，例如：
```
/role list
/role add 研究员 AI技术研究员
/pa 帮我分析大语言模型的发展趋势
```

### 3. 会话管理
可以创建多个会话，并在会话间切换：
```
/l  # 查看会话列表
/t  # 查看会话树
/tc 1  # 切换到第一个会话
```

### 4. 焦点切换
使用`Ctrl+Tab`在输入和输出区域间切换，以便更好地查看输出内容或进行复制操作。

## 功能特性

### 1. 实时交互
- 用户可以在代理执行任务的任何时刻进行干预、提问和修正
- 支持异步消息队列，实现实时驾驭

### 2. 会话管理
- 支持层次化会话结构
- 可以在不同会话间切换、暂停、中止
- 会话状态持久化

### 3. 角色管理
- 可以创建和管理不同的AI角色
- 每个角色可以有不同的职责和能力

### 4. 知识库集成
- 支持知识库搜索和同步
- 可以查询本地知识库内容

### 5. 辩论系统
- 支持多代理辩论模式
- 可以启动包含正方、反方和中立观察者的辩论会话

### 6. 权限控制
- 当工具需要权限时会弹出权限请求对话框
- 用户可以选择允许或拒绝工具执行

### 7. UI增强功能
- 状态栏实时显示系统信息
- 根据Token使用率改变颜色提示
- JSON和代码的语法高亮显示
- 支持焦点切换和文本操作

## 注意事项

1. **依赖项**：确保所有Python依赖已正确安装
2. **模型配置**：系统需要正确配置本地大语言模型
3. **权限控制**：某些工具可能需要用户授权才能执行
4. **会话状态**：会话状态会在系统重启后丢失（除非实现持久化）

## 故障排除

### TUI无法启动
1. 检查是否所有依赖都已安装：`poetry install`
2. 确认Python环境正确配置
3. 检查是否有端口冲突

### 命令无响应
1. 检查命令格式是否正确
2. 确认系统是否处于可接收输入的状态
3. 查看是否有错误信息输出

### 界面显示异常
1. 确认终端支持ANSI转义序列
2. 检查终端窗口大小是否足够
3. 确认字体支持特殊字符显示
