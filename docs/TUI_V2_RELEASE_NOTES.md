# DAIP-LIVE TUI v2.0 发布说明

## 🎉 版本概述

DAIP-LIVE TUI v2.0 是一个重大功能更新版本，新增了4个核心命令，极大地扩展了系统的功能性和用户体验。这个版本专注于知识管理、文档处理和系统优化，为用户提供了完整的AI工作台解决方案。

## 🆕 v2.0 新功能

### 🔧 上下文压缩系统 (`/compact`)
**功能描述：** 智能对话上下文压缩，优化Token使用效率

**主要特性：**
- 三种压缩模式：current（当前）、full（完整）、aggressive（激进）
- 智能内容保留算法，确保重要信息不丢失
- 实时Token使用量监控和压缩效果对比
- 自动在80%使用量时触发压缩警告

**使用场景：**
- 长时间对话后的性能优化
- Token使用量接近限制时的紧急处理
- 系统资源紧张时的手动优化

**命令示例：**
```bash
/compact current      # 压缩当前会话
/compact full         # 完整压缩
/compact aggressive   # 激进压缩
```

### 📚 论文管理系统 (`/doc`)
**功能描述：** 完整的学术论文搜索、下载和管理系统

**主要特性：**
- arXiv API深度集成，支持实时论文搜索
- 批量下载功能，支持最大数量控制
- 论文元数据自动提取和本地缓存
- 多格式论文搜索（标题、摘要、作者、关键词）
- 下载进度显示和错误重试机制

**支持的操作：**
- `download` - 下载论文到本地
- `list` - 列出已下载的论文
- `search` - 搜索本地论文库
- `batch` - 批量下载操作
- `status` - 下载状态检查
- `report` - 下载统计报告

**使用示例：**
```bash
# 下载机器学习相关论文
/doc download "machine learning" --max 5 --arxiv

# 搜索本地论文
/doc search "attention mechanism"

# 列出已下载论文
/doc list
```

### 📝 Wiki知识管理系统 (`/wiki`)
**功能描述：** 个人知识库的创建、组织和导出系统

**主要特性：**
- Markdown格式Wiki页面创建和编辑
- 智能标签分类系统
- 全文搜索和内容索引
- 多格式导出支持（Markdown、HTML、Obsidian、JSON）
- 字数统计和阅读时间估算
- 页面版本历史跟踪

**支持的操作：**
- `create` - 创建新的Wiki页面
- `list` - 列出所有页面
- `search` - 搜索Wiki内容
- `export` - 导出整个Wiki或特定页面
- `delete` - 删除页面
- `import` - 导入外部文档
- `stats` - 统计信息

**使用示例：**
```bash
# 创建学习笔记页面
/wiki create "深度学习基础" --tags "AI,神经网络"

# 搜索相关内容
/wiki search "transformer"

# 导出为Markdown格式
/wiki export markdown ./export
```

### 🔐 权限管理系统 (`/permission`)
**功能描述：** 细粒度的工具访问权限控制系统

**主要特性：**
- 工具级别权限控制
- 用户权限分配和管理
- 权限继承和委托机制
- 权限审计日志记录
- 临时权限支持

**支持的工具：**
- `gemini-cli` - Gemini CLI工具
- `playwright` - 网页自动化工具
- `exa-search` - 搜索工具
- `context7` - 上下文管理工具
- `deepwiki` - Wiki深度搜索
- `paper-downloader` - 论文下载工具
- `format-converter` - 格式转换工具

**使用示例：**
```bash
# 查看当前权限设置
/permission list

# 授予论文下载权限
/permission grant paper-downloader researcher

# 检查特定工具权限
/permission check gemini-cli
```

## 🎯 智能自动补全系统

### 全新补全体验
- **命令补全**：输入 `/` 后按Tab查看所有18个可用命令
- **子命令补全**：智能识别命令结构，提供准确的子命令建议
- **参数补全**：支持格式选项、工具名称等参数的智能补全
- **上下文感知**：根据当前状态提供最相关的补全建议

### 补全示例演示
```bash
# 输入 /comp 后按Tab
/comp → Tab → /compact

# 输入 /compact 后按Tab
/compact → Tab → current, full, aggressive

# 输入 /wiki export 后按Tab
/wiki export → Tab → markdown, html, obsidian, json

# 输入 /permission grant 后按Tab
/permission grant → Tab → gemini-cli, playwright, exa-search, context7...
```
