DAIP-LIVE 项目手册

欢迎来到 DAIP-LIVE (Dynamic AI-driven Project-execution LIVE system)！

DAIP-LIVE 是一个先进的智能协作平台，旨在通过动态的多 AI 角色协同辩论与自动化的敏捷项目执行，探索并解决复杂问题。我们致力于构建一个不仅功能强大，而且过程透明、用户可控的系统，以有效抑制大语言模型（LLM）可能产生的幻觉。

本手册将引导您了解项目的核心功能、技术亮点以及如何与系统进行交互。

1. 核心理念与技术亮点

DAIP-LIVE 的设计哲学是“过程即服务”。我们相信，一个可靠的 AI 协作系统不仅要交付高质量的结果，更要让其决策和推理过程变得透明、可追溯、可干预。

为此，我们实现了以下技术创新：

1.1. 沉浸式终端用户界面 (TUI)

我们摒弃了传统的、一次性的命令行脚本，采用先进的 prompt-toolkit 库构建了一个全屏、实时的终端应用程序。

  • 实时反馈: 辩论的每一轮发言、系统的每一次内部技术活动（在 --verbose 模式下）都会实时滚动显示在您的屏幕上。
  • 随时介入: 您不再是旁观者。在辩论的任何时刻，您都可以按下 i 键，无缝地介入对话，发表您的观点。您的输入将作为辩论历史的一部分，直接影响后续 AI 角色的思考。
  • 清晰的交互: 屏幕底部始终有清晰的快捷键提示，如 [i] 介入 | [q] 退出，为您提供流畅的交互体验。

1.2. 前后端完全解耦的“无头”引擎

系统的核心——“辩论引擎” (DebateProtocol)——与用户界面（TUI）是完全分离的。

  • 异步队列通信: 后端引擎通过两个标准的 asyncio 队列与前端 TUI 通信：一个用于接收命令（如用户的介入），一个用于广播事件（如新的发言）。
  • 高可扩展性: 这种“无头”设计意味着核心逻辑不依赖于任何特定界面。未来，我们可以轻松地为其开发 Web 界面、桌面应用或其他客户端，而无需修改一行核心代码。
  • 高可测试性: 我们可以独立地对后端引擎进行严格的自动化测试，极大地保证了系统的稳定性和可靠性。

1.3. 智能角色推荐系统

为了解决“技术遗产全覆盖原则”中发现的功能差距，我们恢复并极大地增强了旧有的角色推荐功能。

  • 交互式工作流: 当您发起辩论时，不再需要预先想好所有参与角色。您只需提供一个主题，系统便会启动智能推荐流程。
  • 语义化搜索: 我们创建了一个独立的 RoleRecommenderService，它利用 ChromaDB 向量数据库，将所有角色的描述和专长转化为向量。当您输入主题时，系统会进行语义相似度计算，为您推荐最相关的专家组合。
  • 用户确认: 推荐结果会以清晰的列表形式呈现给您，并由您最终决定是采纳推荐、手动选择还是取消。

1.4. 结构化的事件协议

前端与后端的所有通信都基于一套严格的、使用 Pydantic 定义的事件和命令模型 (events.py, commands.py)。这确保了数据交换的可靠性和明确性，是实现前后端彻底解耦的基石。

2. 快速上手

2.1. 安装

首先，请确保您已安装 Poetry。然后，在项目根目录 d:\DAIP\daip_mvp_project 下运行以下命令来安装所有依赖：

poetry install

此命令会自动创建一个虚拟环境并安装 pyproject.toml 中定义的所有库，包括 prompt-toolkit。

2.2. 运行

我们强烈建议使用 poetry run 来执行命令，以确保使用的是正确的 Python 环境。

基本命令结构:

poetry run python -m src.cli.main start --topic "您的辩论主题" --roles "角色1" --roles "角色2"

示例:

假设您想让一位“技术专家”和一位“伦理学家”就“人工智能是否应该拥有创造力”这个主题进行辩论，您可以运行：

poetry run python -m src.cli.main start --topic "人工智能是否应该拥有创造力" --roles "技术专家" --roles "伦理学家"

运行此命令后，您的终端将进入一个全屏应用，辩论将实时开始。

3. 核心体验要点

3.1. 发起一场辩论

使用 start 命令并提供 --topic 和至少一个 --roles 参数。

3.2. 用户介入

在 TUI 界面运行时：

  • 按下 i 键。
  • 底部的工具栏会变成一个输入提示符。
  • 输入您的观点并按回车。您的发言将立即出现在辩论日志中，并被后续的 AI 角色参考。

3.3. 查看技术细节 (Verbose 模式)

如果您想观察系统内部的技术运作过程，可以在启动时添加 --verbose 标志。这样，您将看到类似 [VERBOSE] SynthesisEngine: Summarizing context... 的实时日志，直观地了解系统正在做什么。

poetry run python -m src.cli.main start --topic "..." --roles "..." --verbose

3.4. 退出应用

在 TUI 界面运行时，随时可以按下 q 键来安全地退出应用程序。
