# P2 知识管理器 (Knowledge Manager)

## 📋 概述

P2模块负责本地知识库的管理、向量化和检索功能。该模块通过语义搜索技术，使系统能够理解和利用用户提供的知识文档。

## 🔧 核心功能

### 知识摄取
- **文档监视**: 监视指定的知识文件夹，自动处理新增或修改的文档
- **格式支持**: 支持多种文档格式(.md, .txt, .pdf, .docx等)
- **增量更新**: 支持增量式知识库更新，避免全量重建

### 向量化服务
- **嵌入模型**: 使用嵌入模型将文本块转换为向量表示
- **分块策略**: 采用合适的文本分块策略以保持语义完整性
- **向量索引**: 构建高效向量索引以加速搜索

### 语义搜索
- **相似度计算**: 基于向量相似度进行语义搜索
- **上下文增强**: 将检索到的知识与当前上下文结合
- **结果排序**: 按相关性对搜索结果进行排序

## 🏗️ 系统架构

### 知识管理组件
- **KnowledgeIngestor**: 知识摄取器，负责文档加载和预处理
- **TextEmbedder**: 文本嵌入器，负责文本向量化
- **VectorStore**: 向量存储，负责向量索引和搜索
- **KnowledgeManager**: 知识管理器，协调各组件工作

### 数据流
1. 文档加载 → 文本分块 → 向量化 → 向量索引
2. 查询向量化 → 向量搜索 → 结果排序 → 上下文组合

## 🧠 技术实现

### 向量数据库
- **FAISS**: 本地向量数据库，提供高效的相似度搜索
- **ChromaDB**: 可选的嵌入式向量数据库
- **索引优化**: 采用合适的索引策略平衡搜索精度和性能

### 文本处理
- **分块策略**: 采用递归字符分块等策略保持语义完整性
- **预处理**: 文本清理、标准化和特殊标记处理

## 🔍 搜索功能

### 语义搜索
- **多语言支持**: 支持多语言文档的向量化和搜索
- **上下文长度**: 处理长文档的分块和重组
- **查询增强**: 使用查询扩展技术提高搜索质量

### 结果质量
- **相关性排序**: 基于向量相似度和元数据进行排序
- **去重机制**: 避免相似内容的重复返回
- **元数据保留**: 保留文档来源等元数据信息
