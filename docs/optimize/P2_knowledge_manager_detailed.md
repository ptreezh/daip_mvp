# P2 知识管理器 - 详细设计 (P2 Knowledge Manager - Detailed Design)

## 📋 概述
P2模块提供本地知识库管理、向量化和检索功能，是系统的智能基础。

## 🔧 核心功能详解

### 知识摄取系统
- **文档监视器**: 监视指定目录的文档变化
- **多格式支持**: 支持.md、.txt、.pdf、.docx等格式
- **增量更新**: 检测文档变化并进行增量更新

### 向量化服务
- **嵌入模型**: 集成多种嵌入模型提供者
- **分块策略**: 采用递归字符分块等策略保持语义完整性
- **向量索引**: 使用FAISS或ChromaDB构建高效索引

### 语义搜索
- **相似度计算**: 基于向量相似度的语义搜索
- **上下文增强**: 结合上下文进行智能检索
- **结果排序**: 按相关性进行结果排序

## 🏗️ 系统架构详情

### 核心组件架构
```
┌─────────────────────────────────────┐
│          KnowledgeManager           │
├─────────────────────────────────────┤
│  ┌─────────────────┐ ┌─────────────┐│
│  │ KnowledgeIngestor │ │ TextEmbedder││
│  │   (摄取器)       │ │  (嵌入器)   ││
│  └─────────────────┘ └─────────────┘│
│  ┌─────────────────┐ ┌─────────────┐│
│  │ VectorStore     │ │ Knowledge   ││
│  │   (向量存储)     │ │  Manager    ││
│  └─────────────────┘ └─────────────┘│
└─────────────────────────────────────┘
```

### 数据处理流水线
1. **文档加载** → 文本分块 → 向量化 → 向量索引
2. **查询向量化** → 向量搜索 → 结果排序 → 上下文组合

### 组件职责
- **KnowledgeIngestor**: 文档加载和预处理
- **TextEmbedder**: 文本向量化
- **VectorStore**: 向量存储和搜索
- **KnowledgeManager**: 协调各组件

## 🧠 技术实现详解

### 向量数据库
- **FAISS**: 本地向量数据库，提供高效相似度搜索
- **ChromaDB**: 可选的嵌入式向量数据库
- **索引策略**: 选择合适的索引类型平衡性能和精度

### 文本处理
- **分块算法**: 保持语义完整性的分块策略
- **预处理**: 文本清理和标准化
- **上下文维护**: 保留文本的上下文关系

## 🔍 检索功能详解

### 语义搜索机制
- **多语言支持**: 支持多种语言的向量化和搜索
- **长文档处理**: 分块和重组策略
- **查询扩展**: 提高搜索质量的扩展技术

### 结果质量
- **相关性排序**: 基于相似度的排序
- **去重机制**: 避免重复内容
- **元数据保留**: 保留来源信息

## 🔐 安全考虑

### 访问控制
- **权限管理**: 控制知识库访问权限
- **数据隔离**: 不同会话的数据分离
- **隐私保护**: 保护私有信息
