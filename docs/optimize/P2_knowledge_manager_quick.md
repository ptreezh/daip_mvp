# P2 知识管理器 - 快速概览 (P2 Knowledge Manager - Quick Overview)

## 🎯 核心功能
P2模块负责本地知识库的管理、向量化和检索功能。

## 🔧 主要职责
- **知识摄取**: 监视和处理知识文档
- **向量化服务**: 文本向量化和索引
- **语义搜索**: 基于向量相似度的搜索
- **知识管理**: 知识库的组织和维护

## 📊 核心组件
- **KnowledgeIngestor**: 知识摄取器
- **TextEmbedder**: 文本嵌入器
- **VectorStore**: 向量存储
- **KnowledgeManager**: 知识管理器

## 🚀 快速启动
- **格式支持**: .md, .txt, .pdf, .docx 等
- **向量库**: FAISS, ChromaDB
- **搜索方式**: 语义搜索
- **更新策略**: 增量更新
