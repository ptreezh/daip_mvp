# P5 代理引擎 (Agent Engine) - 模块入口

## 📋 快速概览
P5模块是DAIP-LIVE系统的核心，负责代理的执行和管理。

- **核心类**: `AgentExecutor`
- **主要功能**: 代理执行、事件流生成、状态管理
- **执行模式**: 任务导向模式、对话模式
- **集成组件**: 与P3(模型)、P4(工具)、P0(接口)深度集成
