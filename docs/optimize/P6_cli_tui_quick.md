# P6 CLI/TUI界面 - 快速概览 (P6 CLI/TUI Interface - Quick Overview)

## 🎯 核心功能
P6模块提供命令行界面和终端用户界面。

## 🔧 主要职责
- **CLI接口**: Typer实现的命令行界面
- **TUI界面**: Textual实现的终端界面
- **用户交互**: 命令处理和用户输入
- **状态显示**: 实时显示系统状态

## 📊 核心组件
- **命令系统**: daip命令及其子命令
- **TUI应用**: 基于Textual的界面
- **事件处理**: 用户交互事件处理
- **复制功能**: 内容复制到剪贴板

## 🚀 快速启动
- **启动命令**: `daip run`
- **辩论功能**: `daip debate start`
- **维基功能**: `daip wiki create`
- **自然语言**: `daip ask`
