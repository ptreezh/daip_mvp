# P8.1 辩论系统 - 快速概览 (P8.1 Debate System - Quick Overview)

## 🎯 核心功能
P8.1辩论系统负责组织和管理结构化的多AI角色辩论流程。

## 🔧 主要职责
- **辩论流程**: 管理辩论的多轮次发言
- **角色调度**: 按规则调用不同AI角色
- **历史记录**: 记录每个角色的发言和论点
- **结果输出**: 生成辩论记录和分析报告

## 📊 核心组件
- **DebateManager**: 辩论流程中央协调器
- **DebateHistoryTracker**: 辩论历史追踪器
- **ConsensusGenerator**: 共识生成器
- **DebateEvents**: 辩论相关事件定义

## 🚀 快速启动
- **启动辩论**: `daip debate start`
- **多角色**: 支持多个AI角色参与
- **多轮次**: 支持多轮辩论流程
- **历史记录**: 完整辩论过程记录
