# P8 高级功能系统 - 快速概览 (P8 Advanced Systems - Quick Overview)

## 🎯 核心功能
P8模块包含系统的高级功能实现：辩论系统、人类助手系统和维基系统。

## 🔧 主要职责
- **辩论系统**: 多AI角色辩论组织
- **人类助手**: 个人助理功能
- **维基系统**: 协作知识库管理
- **高级功能**: 复杂业务逻辑实现

## 📊 核心组件
- **DebateManager**: 辩论管理器
- **PersonalAssistant**: 个人助手
- **WikiManager**: 维基管理器
- **高级服务**: 高级业务功能

## 🚀 快速启动
- **辩论功能**: `daip debate` 命令
- **助手功能**: `daip ask` 智能交互
- **维基功能**: `daip wiki` 命令
- **多角色**: 支持多AI角色协作
