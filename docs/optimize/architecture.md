## 🔄 数据流 (Data Flow)

### 1. 用户输入处理流程
```
用户输入 → 意图识别 → 服务路由 → 执行引擎 → 结果返回
```

### 2. 多模型辩论流程
```
辩论主题 → 角色分配 → 模型选择 → 轮次执行 → 结果整合 → 历史记录
```

### 3. 知识检索流程
```
查询 → 向量化 → 相似度计算 → 结果排序 → 上下文注入
```

## 🧱 核心组件 (Core Components)

### Agent引擎
- **路径**: `src/daip_live/agent_engine/`
- **职责**: 任务执行和流程控制
- **接口**: `executor.py`, `workflow_executor.py`

### 意图识别器
- **路径**: `src/daip_live/agent_engine/enhanced_intent_recognizer.py`
- **职责**: 自然语言理解与意图分类
- **算法**: 混合规则+模型意图识别

### 内存服务
- **路径**: `src/daip_live/core/universal_memory_system.py`
- **职责**: 会话管理和长期记忆
- **类型**: 短期记忆（会话）+ 长期记忆（持久化）

### 角色管理
- **路径**: `src/daip_live/p4_role_manager_tools/role_manager.py`
- **职责**: AI角色配置与能力管理
- **模型**: 基于角色模型管理器

### 知识管理
- **路径**: `src/daip_live/p2_knowledge_manager/`
- **职责**: 文档向量化、存储和检索
- **技术**: FAISS向量数据库

## 🔧 依赖注入容器 (Dependency Injection Container)

- **路径**: `src/daip_live/container.py`
- **职责**: 组件生命周期管理和依赖注入
- **优势**: 模块化、可测试、可扩展

### 注入的服务
- `session_manager` - 会话管理器
- `role_manager` - 角色管理器
- `model_provider` - 模型提供者
- `knowledge_manager` - 知识管理器
- `debate_history_tracker` - 辩论历史追踪器
- `intent_recognizer` - 意图识别器
- `enhanced_debate_manager` - 增强辩论管理器

## 📦 模块划分 (Module Division)

### P0: 核心接口
- **路径**: `src/daip_live/p0_core_interfaces/`

- **路径**: `src/daip_live/p1_data_persistence/`

- **路径**: `src/daip_live/p2_knowledge_manager/`
- **职责**: 知识库管理、向量化和检索

### P3: 模型提供者
- **路径**: `src/daip_live/p3_model_provider/`
- **职责**: AI模型接口统一和模型调用管理

### P4: 角色管理工具
- **路径**: `src/daip_live/p4_role_manager_tools/`
- **职责**: AI角色配置、管理和能力定义

### P5: Agent引擎
- **路径**: `src/daip_live/p5_agent_engine/`
- **职责**: 任务执行、流程控制和意图处理

### P6: CLI/TUI界面
- **路径**: `src/daip_live/p6_cli_tui/`
- **职责**: 命令行界面和终端用户界面

### P7: GUI界面
- **路径**: `src/daip_live/p7_gui/`
- **职责**: 图形用户界面

### P8: 高级功能模块
- **路径**:

  - `src/daip_live/p8_wiki_system/` - Wiki系统

## 🔌 外部集成 (External Integrations)

### 模型提供商
- **OpenAI API**: 通过LiteLLM接口
- **Anthropic Claude**: 通过LiteLLM接口
- **本地Ollama**: 直接API调用
- **其他模型**: 通过LiteLLM支持的模型

### 数据库
- **向量存储**: FAISS (本地向量数据库)
- **关系存储**: SQLAlchemy (支持SQLite、PostgreSQL等)

### 工具接口
- **文档处理**: python-docx, arXiv API
- **Web检索**: scholarly, requests
- **剪贴板**: pyperclip
