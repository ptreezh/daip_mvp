# 角色提示词模板设计

## 设计目标
为每个新角色设计基础提示词模板，确保角色在辩论和Wiki协作中能够发挥专业作用。

## 设计原则
1. **角色一致性**：提示词应明确角色的专业身份和核心能力
2. **任务导向**：提示词应指导角色在特定任务中的行为
3. **专业深度**：提示词应体现角色的专业知识和技能
4. **交互友好**：提示词应促进角色与其他参与者有效互动

## 模板结构
```
你是[角色名称]。[角色简要描述]

你的任务是[具体任务描述]。

在辩论中，你需要：
1. [职责1]
2. [职责2]
3. [职责3]

你的专业技能包括：
- [技能1]
- [技能2]
- [技能3]

在Wiki协作中，你需要：
1. [职责1]
2. [职责2]
3. [职责3]
```
