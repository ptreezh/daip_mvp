## ⌨️ 快捷键指南

### 全局快捷键
- **Ctrl+Tab** - 切换输入/输出焦点
- **Ctrl+C** - 复制所有日志内容
- **Ctrl+E（两次）** - 退出应用（第一次按显示提示，2秒内再按一次退出）
- **Escape** - 退出输出模式
- **Ctrl+A** - 全选（仅在输入模式）
- **Tab/Enter** - 确认自动补全建议
- **上下箭头** - 选择自动补全建议

### 自动补全快捷键
- 输入 `/` 后按 `Tab` 键显示所有可用指令
- 输入指令前缀后按 `Tab` 键显示相关指令建议
- 使用上下箭头选择建议，按 `Enter` 确认

## 🎮 核心功能

### 🎭 辩论系统（新增功能）
- **`/debate start [topic]`** - 开始新辩论
- **`/debate status`** - 查看辩论状态和进度
- **`/debate stop`** - 停止当前辩论
- **`/debate history`** - 查看辩论历史

**新增特性：**
- ✅ 支持不同模型和角色的辩论
- ✅ 实时辩论状态更新显示
- ✅ 智能角色选择和模型配置
- ✅ 多轮辩论支持
- ✅ 辩论结果保存和回放

### 🤖 角色管理
- **`/role list`** - 列出所有可用AI角色
- **`/role view [role_name]`** - 查看角色详细信息
- **`/role info [role_name]`** - 查看角色配置和工具权限

**内置角色：**
- pro_arguer - 正方辩手
- con_arguer - 反方辩手
- neutral_observer - 中性观察者
- creative_writer - 创意作家
- data_scientist - 数据科学家
- philosophy_thinker - 哲学思考者
- product_manager - 产品经理
- research_analyst - 研究分析师
- tech_analyst - 技术分析师

### 💬 会话管理
- **`/session list`** - 查看所有会话
- **`/session view [session_id]`** - 查看会话详情
- **`/session clear`** - 清除当前会话上下文并重置tokens
- **`/session reset`** - 重置token使用量为零
- **`/session create [type]`** - 创建新会话（chat/debate/workflow）
- **`/session info [session_id]`** - 查看会话详情
- **`/session history [session_id]`** - 查看会话历史

### 🧠 知识库系统
- **`/knowledge sync`** - 同步知识库文档
- **`/knowledge search [query]`** - 搜索知识库
- **`/knowledge status`** - 查看知识库状态

### 🎯 智能助手
- **`/pa [prompt]`** - 个人助手快捷指令
- **`/pa help`** - 查看助手功能
- **`/pa config`** - 配置助手设置

### 🛠️ 系统管理
- **`/model list`** - 列出可用模型
- **`/model info [model_name]`** - 查看模型信息
- **`/help`** - 显示帮助信息
- **`/quit`** - 退出应用

## 🎨 界面特性

### 焦点管理
- **输入模式**：可以在底部输入框输入指令
- **输出模式**：可以浏览和复制日志内容
- 使用 `Ctrl+Tab` 或鼠标点击切换焦点

### 状态显示
- 实时显示当前模型名称
- 显示令牌使用情况（已用/总计百分比）
- 显示系统活动和事件处理数量
- 辩论状态实时更新（当前轮次、参与者等）

### 🎯 Token管理和自动压缩
- **自动监控**：实时监控token使用情况
- **自动压缩**：当token使用量达到80%时自动触发上下文压缩（预防性压缩）
- **手动控制**：
  - `/session clear` - 清除会话上下文并重置tokens
  - `/session reset` - 仅重置token使用量为零
- **压缩策略**：
  - 智能摘要压缩：使用LLM生成8维度结构化摘要
  - 保留最近3轮关键对话
  - 80%触发，预防性压缩策略
- **状态提示**：达到80%时显示预警和压缩进度

### 自动补全系统
- **指令补全**：输入 `/` 显示所有指令
- **参数补全**：自动补全角色名、会话ID等
- **智能建议**：基于上下文提供相关建议
- **实时更新**：输入时动态更新建议列表

### 富文本显示
- 语法高亮和颜色编码
- 事件类型区分显示
- 错误信息醒目提示
- 权限请求对话框
