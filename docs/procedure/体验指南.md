# DAIP-LIVE 辩论模型切换功能体验指南

## 🚀 快速启动

### 1. 启动服务
```bash
# 启动Ollama
ollama serve

# 下载模型（可选）
ollama pull llama3:8b
ollama pull mistral:7b
```

### 2. 启动应用
```bash
cd D:\DAIP\refactdoc
python -m daip_live.cli
```

## 🎯 体验步骤

### 基础体验
1. **查看可用角色**
   ```
   /role list
   ```

2. **启动简单辩论**
   ```
   /debate start 人工智能发展 --roles pro_arguer,con_arguer --rounds 2
   ```

3. **观察状态栏变化**
   - 注意底部状态栏的模型显示
   - 观察不同角色发言时的模型切换

### 高级体验
1. **多模型辩论**
   ```
   /debate start AI伦理问题 --roles tech_analyst,ethics_expert --rounds 3
   ```

2. **实时监控**
   - 观察Token使用量变化
   - 注意模型切换时的状态更新
   - 查看辩论进度信息

3. **测试错误处理**
   - 尝试使用不存在的角色名
   - 观察系统的错误处理机制

## 📊 观察要点

### 状态栏信息
- **Model显示**: `模型名 (角色名)` 格式
- **Token使用**: 实时更新的Token计数
- **辩论状态**: 显示当前轮次和发言者
- **系统状态**: Thinking/Debating/Idle

### 日志信息
- 辩论开始信息
- 模型切换通知
- 角色发言状态
- 辩论完成总结

## 🎮 交互命令

### 辩论相关
```bash
/debate start <主题> --roles <角色列表> --rounds <轮数>
/debate help  # 查看帮助
```

### 角色管理
```bash
/role list          # 列出所有角色
/role view <角色名>  # 查看角色详情
```

### 系统控制
```bash
/session clear      # 清除会话
/session status     # 查看状态
/model <模型名>      # 切换模型
/help              # 查看帮助
/quit              # 退出应用
```

## 🔍 预期效果

### 正常流程
1. 启动辩论后，状态栏显示辩论信息
2. 不同角色发言时，模型显示实时切换
3. Token使用量持续更新
4. 辩论结束后状态重置

### 状态栏示例
```
# 初始状态
Model: llama3:8b | Tokens: 0/8192 (0%) | Status: Idle | Focus: Input

# 辩论中 - 技术分析师
Model: llama3:8b (tech_analyst) | Tokens: 1500/8192 (18%) | Status: Debating | Focus: Input

# 辩论中 - 伦理专家
Model: mistral:7b (ethics_expert) | Tokens: 3200/8192 (39%) | Status: Debating | Focus: Input

# 辩论结束
Model: llama3:8b | Tokens: 4500/8192 (55%) | Status: Idle | Focus: Input
```
