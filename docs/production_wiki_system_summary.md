## 🔧 使用示例

### 基本使用

```python
from daip_live.tui_v1.wiki.production_wiki_system import create_production_wiki_system

# 创建生产级Wiki系统
system = create_production_wiki_system(
    storage_path="./wiki_data",
    embedding_dimension=384,
    max_concurrent_processors=4
)

# 添加文档
document_id = await system.add_document(
    "document.pdf",
    metadata=DocumentMetadata(
        title="重要文档",
        author="张三",
        tags=["AI", "机器学习"]
    )
)

# 搜索文档
results = await system.search(
    "机器学习算法",
    search_type=SearchType.HYBRID,
    top_k=10
)

# 获取系统指标
metrics = system.get_system_metrics()
print(f"处理文档数: {metrics['documents_count']}")
print(f"搜索响应时间: {metrics['processing_metrics']['searches_performed']['avg_duration']}")
```

### 高级功能
