# 快捷命令功能设计文档

## 1. 功能概述

为提升用户交互效率，需要在CLI和TUI中实现一组快捷命令，通过简短的前缀指令快速访问核心功能。

## 2. 快捷命令列表

| 快捷命令 | 对应功能 | 说明 |
|---------|---------|------|
| /pa | 个人助手 | 启动个人助手执行任务 |
| /role | 角色管理 | 角色的增删改查操作 |
| /0 | 知识库同步 | 初始化或同步项目目录下的知识库 |
| /debate | 启动辩论 | 启动一个多智能体辩论 |
| /v | 搜索会话历史 | 搜索和查看历史会话 |

## 3. 实现方案

### 3.1 CLI实现
在现有CLI结构基础上，添加新的命令解析逻辑，识别以"/"开头的快捷命令并映射到相应功能。

### 3.2 TUI实现
扩展TUI输入处理逻辑，识别快捷命令并执行相应功能，同时保持与Agent的交互能力。

## 4. 详细设计

### 4.1 个人助手快捷命令 (/pa)
- 命令格式: `/pa <任务描述>`
- 功能: 直接启动Agent执行用户指定的任务
- 实现: 复用现有的`run`命令逻辑

### 4.2 角色管理快捷命令 (/role)
- 命令格式: 
  - `/role add <角色名> <描述>` - 添加新角色
  - `/role view <角色名>` - 查看角色详情
  - `/role list` - 列出所有角色
- 功能: 管理AI角色配置
- 实现: 基于RoleManager实现角色的增查操作

### 4.3 知识库搜索快捷命令 (/0)
- 命令格式: `/0` 或 `/0 <查询内容>`
- 功能: 
  - 无参数时同步知识库
  - 有参数时搜索知识库内容
- 实现: 复用现有的知识库同步和搜索功能

### 4.4 辩论启动快捷命令 (/debate)
- 命令格式: `/debate <主题> [角色1,角色2]`
- 功能: 快速启动辩论会话
- 实现: 复用现有的debate start命令逻辑

### 4.5 会话历史搜索快捷命令 (/v)
- 命令格式: `/v [查询关键词]`
- 功能: 搜索历史会话记录
- 实现: 基于SessionManager实现会话搜索功能

## 5. 技术实现要点

1. 命令解析器需要能区分快捷命令和普通文本输入
2. 快捷命令在CLI和TUI中应保持一致的行为
3. 需要处理命令参数解析和验证
4. 错误处理和用户提示信息需要清晰明确
