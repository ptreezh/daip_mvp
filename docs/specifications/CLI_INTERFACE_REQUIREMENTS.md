# CLI接口需求文档 (单机版)

## 1. 功能概述

CLI（命令行界面）是DAIP-LIVE（单机版）的核心用户交互方式之一，为用户提供强大、高效、可脚本化的系统控制与操作能力。

## 2. 核心功能需求

### 2.1 命令解析与执行
- 使用成熟的CLI框架（如Typer, Click）构建，提供结构清晰的子命令。
- 解析用户输入的命令、参数和选项。
- 调用对应的内部模块执行命令并向终端返回清晰的结果。

### 2.2 系统配置管理
- **提供命令**来查看和修改`config.yaml`中的关键配置。
- `daip config view`: 显示当前配置。
- `daip config set model_provider.default_provider openai`: 切换默认的LLM提供者。
- **提供命令**来安全地管理本地存储的API密钥。

### 2.3 个人助理功能
- 提供一个统一的入口命令（如 `daip pa ...`）与个人助理交互。
- 支持直接提问、执行复杂任务等。

### 2.4 辩论与会话控制
- 提供命令来启动、查看和管理会话（如 `daip debate start "主题"`）。
- 支持列出历史会话并回顾内容。

### 2.5 角色管理
- 提供命令来列出、查看、创建和删除本地的角色配置文件。

### 2.6 知识库操作
- **提供命令**来管理本地知识库文件夹。
- `daip knowledge sync`: 手动触发对知识库文件夹的扫描和索引。
- `daip knowledge search "查询内容"`: 对已索引的知识库进行语义搜索。

## 3. 非功能需求

### 3.1 用户体验
- **帮助信息**: 每个命令和子命令都必须提供清晰、有用的帮助信息（通过`--help`选项）。
- **自动补全 (可选)**: 可为CLI提供Tab自动补全功能，提升使用效率。
- **友好的反馈**: 操作成功、失败或进行中，都应有不同颜色或格式的清晰输出。错误提示应尽可能指出问题原因。

### 3.2 性能要求
- **快速响应**: CLI启动和命令的即时响应时间应在毫秒级。
- **高效处理**: 对于数据密集型任务（如知识同步），应提供进度条反馈。

### 3.3 可靠性
- **稳定的执行**: 命令执行过程中不应意外崩溃，对用户输入有基本的校验。
- **明确的错误处理**: 当发生错误（如配置文件错误、模型连接失败）时，必须向用户报告具体的错误信息。
