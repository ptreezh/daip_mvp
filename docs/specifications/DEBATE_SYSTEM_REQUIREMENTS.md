# 辩论系统需求文档 (单机版)

## 1. 功能概述

辩论系统是DAIP-LIVE（单机版）中的一个核心**功能模块**，通过多AI角色结构化辩论，帮助用户对复杂问题进行深入分析，以实现高质量决策和共识形成。

## 2. 核心功能

### 2.1 辩论流程管理
- 标准化辩论流程定义（例如，正方、反方、中立观察员的发言次序）。
- 多轮次辩论控制，可由用户预设或动态调整。
- 辩论状态跟踪（如：进行中、已暂停、已完成）。

### 2.2 角色参与机制
- 角色根据其自身设定（个性、专长）自动生成观点。
- 角色能够对其他角色的观点提出论据支持或反驳。
- 系统根据预设规则控制发言顺序。

### 2.3 共识形成
- 在辩论结束后，调用LLM对整个过程进行多维度评估。
- 对关键论点进行质量评分。
- 自动生成包含主要观点、分歧和最终共识的摘要报告。

### 2.4 辩论质量控制
- 对AI角色的发言内容进行基本的逻辑一致性检查。
- 通过特定的提示词工程（Prompt Engineering）技术，抑制AI产生内容幻觉。
- **新增偏见检测机制**: 在共识生成阶段自动注入检测提示词（如"请分析上述观点是否存在文化/性别/专业领域偏见"），并在最终报告中标注潜在偏见风险点。

## 3. 非功能需求

### 3.1 公正性
- 系统应为所有参与辩论的AI角色提供中立的辩论环境和公平的发言机会。
- 最终的共识评估标准应是透明的，并可由用户调整。

### 3.2 智能化
- 辩论流程应自动化，用户只需设定主题和参数即可启动。
- 系统能对辩论内容进行智能分析，提取关键信息。

### 3.3 可追溯性
- **本地化记录**: 完整的辩论记录（每一轮的发言）和最终的总结报告，都必须被完整地记录在**本地SQLite数据库**中，与对应的会话相关联。
- **可审计的决策过程**: 用户可以随时回顾任何一场历史辩论的完整过程，理解决策是如何形成的。
