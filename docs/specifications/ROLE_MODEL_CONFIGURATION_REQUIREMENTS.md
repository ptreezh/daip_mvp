# 角色模型配置系统需求规范说明书

## 1. 项目概述

### 1.1 背景
当前辩论系统中的所有角色都使用相同的模型配置，缺乏灵活性和针对性。为了提升辩论质量和角色表现，需要实现每个角色使用不同模型的功能。

### 1.2 目标
- 为每个角色配置独立的模型参数
- 支持辩论专用的模型配置
- 提供模型选择和优先级管理
- 保持向后兼容性

### 1.3 范围
- 角色配置文件扩展
- 模型配置管理
- 辩论系统集成
- 工具和命令行接口

## 2. 功能需求

### 2.1 角色配置扩展
#### 2.1.1 模型配置支持
- **功能**: 角色配置文件支持多个模型配置
- **描述**: 每个角色可以配置多个可用模型，包括模型名称、提供者、参数等
- **优先级**: 高

#### 2.1.2 主模型设置
- **功能**: 支持设置主模型（默认使用的模型）
- **描述**: 每个角色必须有一个主模型配置
- **优先级**: 高

#### 2.1.3 辩论专用配置
- **功能**: 支持辩论专用的模型配置
- **描述**: 角色可以设置在辩论中使用不同的模型参数
- **优先级**: 中

### 2.2 模型参数配置
#### 2.2.1 基础参数
- **功能**: 支持配置模型的基础参数
- **描述**: 包括 temperature、max_tokens、top_p、frequency_penalty、presence_penalty
- **优先级**: 高

#### 2.2.2 模型选择
- **功能**: 支持选择不同的模型（GPT-4、Claude-3等）
- **描述**: 可以配置使用不同提供商的模型
- **优先级**: 高

#### 2.2.3 参数验证
- **功能**: 验证模型参数的有效性
- **描述**: 确保配置的参数在合理范围内
- **优先级**: 中

### 2.3 辩论系统集成
#### 2.3.1 模型映射
- **功能**: 在辩论中为每个角色使用对应的模型配置
- **描述**: 根据角色配置自动选择合适的模型
- **优先级**: 高

#### 2.3.2 模型实例管理
- **功能**: 管理不同模型的实例
- **描述**: 高效管理多个模型实例，避免重复创建
- **优先级**: 中

#### 2.3.3 Token使用跟踪
- **功能**: 分别跟踪每个模型的token使用情况
- **描述**: 为每个角色-模型组合单独统计token使用
- **优先级**: 中

### 2.4 配置管理
#### 2.4.1 配置文件格式
- **功能**: 定义YAML配置文件格式
- **描述**: 扩展现有的角色配置文件格式
- **优先级**: 高

#### 2.4.2 配置验证
- **功能**: 验证配置文件的正确性
- **描述**: 加载配置时进行格式和逻辑验证
- **优先级**: 高

#### 2.4.3 默认配置
- **功能**: 提供合理的默认配置
- **描述**: 新角色自动获得默认模型配置
- **优先级**: 中

## 3. 技术需求

### 3.1 架构设计
#### 3.1.1 模块化设计
- **功能**: 采用模块化设计
- **描述**: 角色模型配置功能作为独立模块
- **优先级**: 高

#### 3.1.2 依赖注入
- **功能**: 使用依赖注入模式
- **描述**: 支持依赖注入和测试
- **优先级**: 高

#### 3.1.3 配置缓存
- **功能**: 实现配置缓存机制
- **描述**: 提高配置加载性能
- **优先级**: 中

### 3.2 性能需求
#### 3.2.1 加载性能
- **功能**: 配置加载不应影响系统启动时间
- **描述**: 角色配置加载应在100ms内完成
- **优先级**: 中

#### 3.2.2 内存使用
- **功能**: 控制内存使用量
- **描述**: 每个角色配置对象应小于10KB
- **优先级**: 中

### 3.3 兼容性需求
#### 3.3.1 向后兼容
- **功能**: 保持向后兼容性
- **描述**: 现有角色配置文件仍可正常使用
- **优先级**: 高

#### 3.3.2 错误处理
- **功能**: 优雅处理配置错误
- **描述**: 配置错误不应导致系统崩溃
- **优先级**: 高

## 4. 接口需求

### 4.1 配置文件接口
#### 4.1.1 YAML格式
```yaml
persona: "角色描述"
tools: ["tool1", "tool2"]
model_configs:
  - model_name: "gpt-4"
    provider: "openai"
    max_tokens: 4000
    temperature: 0.7
    top_p: 1.0
    frequency_penalty: 0.0
    presence_penalty: 0.0
    is_primary: true
debate_model_config:
  model_name: "gpt-4"
    provider: "openai"
    max_tokens: 3000
    temperature: 0.5
    is_primary: true
```
