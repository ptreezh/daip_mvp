# Agent执行引擎需求文档 (v3.0)

## 1. 功能概述

Agent执行引擎是DAIP-LIVE系统的核心，它取代了传统的、基于静态定义的“工作流引擎”。本引擎的核心思想是**让AI Agent拥有自主规划和动态执行的能力**，而非仅仅遵循预设的步骤。它通过一个**`Todo`清单系统**进行任务规划，并通过一个**`Task`工具**来派生子Agent以处理复杂任务。

## 2. 核心机制

### 2.1 `Todo`清单系统 (任务规划机制)
- **Agent自主规划**: 当接到一个高阶目标时，主Agent的首要任务是调用内置的`TodoWrite`工具，**为自己制定一个初步的、可执行的计划清单**。这个清单对用户是可见的。
- **状态跟踪与动态调整**: Agent在执行过程中，会不断调用`TodoWrite`工具来更新任务的状态（如 `pending`, `in_progress`, `completed`），或根据新发现动态添加、修改任务项。
- **优先级排序**: `Todo`系统必须支持任务的优先级排序，确保Agent能聚焦于最重要的任务。

### 2.2 `Task`工具与子Agent派生
- **复杂任务分解**: 对于`Todo`清单中的复杂任务，主Agent可以通过调用一个特殊的`Task`工具，派生一个或多个并行的、隔离的子Agent来完成。
- **选择性上下文继承 (关键)**: 为兼顾能力与效率，子Agent的上下文初始化必须采用**选择性继承**策略。主Agent在调用`Task`工具时，必须能参数化地指定子Agent需要继承哪些信息，例如：
  - `inherit_knowledge`: 继承哪些相关的知识片段。
  - `inherit_history`: 继承最近的N条对话历史。
  - `inherit_todos`: 继承部分相关的父任务或兄弟任务的状态。
- **并发执行**: 引擎必须支持主Agent并行地调用多个`Task`工具，派生出多个子Agent来同时处理不同的子任务。

### 2.3 主Agent执行循环 (Think-Act Cycle)
主Agent的执行遵循一个持续的“思考-行动”循环，并与用户的实时指令交互：
1.  **观察 (Observe)**: 
    *   检查`Todo`清单，确定当前最高优先级的待办任务。
    *   **非阻塞地检查**来自UI/TUI的**异步消息队列**中是否有用户的新指令。
2.  **思考 (Think)**: 
    *   **指令优先**: 如果有用户新指令，优先处理该指令，并可能因此修改`Todo`清单（例如，增加新任务、取消旧任务）。
    *   **常规规划**: 如果没有新指令，则根据当前`Todo`任务，规划下一步的具体行动（例如，调用哪个工具）。
3.  **行动 (Act)**: 执行决策，调用`ToolManager`的`execute_tool`方法来执行工具。

#### 2.3.1 代码生成的“生成即合规”子循环
当`execute_tool`执行的是一个**代码生成类**的工具时，必须触发一个特殊的子循环，以确保代码质量：
1.  **生成**: LLM生成代码内容，返回给Agent引擎。
2.  **检查**: 引擎**不直接接受**此代码，而是将其存入临时文件，并在沙箱环境中，依次调用`ruff format`, `ruff check`, `mypy`对其进行自动化检查。
3.  **若合规**: 所有检查通过，则认为代码有效，子循环结束，代码可以被写入文件或进行下一步操作。
4.  **若不合规**: 检查失败，引擎将捕获到的错误信息（如`mypy`的类型错误），连同原始代码，**再次提交给LLM**，并下达指令：“你生成的代码未能通过质量检查，错误如下：`{error_message}`。请修正你的代码后，重新提供完整版本。” 然后回到第1步。
5.  此“生成-检查-修正”的闭环最多可重试2次，以防止无限循环。

4.  循环往复，直到`Todo`清单中的所有任务都已完成，或被用户中断。

## 3. 非功能需求

- **可靠性**: `Todo`清单的状态必须被准确地持久化到SQLite中。应用重启后应能恢复未完成的任务列表。
- **可追溯性**: 所有Agent（包括子Agent）的思考链、工具调用和执行结果都必须被详细记录。
- **性能**: 子Agent的实例化过程应是轻量级的。异步消息队列的检查不应阻塞主循环的执行。
- **实现方式**: 推荐采用**混合线程模型**来实现异步消息队列：UI在一个独立线程中接收用户输入并放入一个线程安全的`queue.Queue`，主Agent的同步执行循环则非阻塞地轮询这个队列。
