# DAIP-LIVE 用户手册 (v3.0 Final)

## 1. 系统概述

DAIP-LIVE (单机版) 是一个运行在您个人电脑上的**动态AI执行引擎**。它不仅仅是一个聊天机器人，更是一个能理解复杂目标、自主规划、并协同多种AI角色和工具来完成任务的智能平台。

本系统**以本地大语言模型为核心，云端模型为辅助**，所有核心功能均可在离线环境下运行，确保了您的隐私和数据安全。

## 2. 安装与配置

### 2.1 系统要求
我们提供分层硬件推荐，以帮助您获得最佳体验：
- **基础配置 (云端模型为主)**: 16GB RAM, 现代4核以上CPU。
- **推荐配置 (本地7B级模型)**: 16GB RAM, 8GB VRAM NVIDIA GPU。
- **专业配置 (本地13B+模型)**: 32GB+ RAM, 16GB+ VRAM NVIDIA GPU。

### 2.2 安装步骤
1.  **安装Python与Git**: 确保您的系统已安装Python (3.9+) 和 Git。
2.  **下载项目代码**: `git clone https://github.com/ptreezh/daip_mvp.git && cd daip_mvp_project`
3.  **安装项目依赖**: `pip install poetry && poetry install`
4.  **安装Pandoc**: 为了支持文档格式转换，请访问 [pandoc.org](https://pandoc.org/installing.html) 下载并安装。应用启动时会自动检查，若未安装会禁用相关功能并提示。

> **未来展望**: 我们计划在未来版本中提供**一键安装包**，届时您将无需手动安装任何依赖。

### 2.3 配置
系统通过`config.yaml`文件进行配置。您可以复制`config.yaml.example`来创建您的配置。

- **分层配置**: 您可以在软件根目录放置一个全局`config.yaml`。此外，还可以在您的任何项目文件夹下创建一个`.daip/config.yaml`文件。当您在此文件夹下运行时，项目级配置将**覆盖**全局配置，非常适合为不同项目设置不同的AI模型或权限。

- **致Windows用户**: 为获得最佳体验，请使用 **Windows Terminal** 作为命令行工具。

## 3. 理解DAIP-LIVE的工作哲学

DAIP-LIVE的交互模式与传统AI助手有很大不同。理解以下几点能帮助您更好地驾驭它：

### 3.1 AI的工作计划板：`Todo`清单
当您给Agent一个复杂任务时（例如“帮我分析这个项目”），它不会立即执行。相反，它会首先在界面上展示一个**`Todo`清单**——这是它对任务的分解和工作计划。在执行过程中，您会看到任务被逐一标记为“进行中”和“已完成”，让您对它的工作进度一目了然。

### 3.2 实时驾驭：在AI工作时下达新指令
本系统最核心的交互革命，是您**无需等待AI完成当前任务**。在AI工作的任何时候，您都可以在输入框中输入新的指令或问题。这些指令会被放入一个“消息队列”中，AI在完成当前步骤后，会立刻检查您的新指令，并据此**动态调整**它的后续计划。

### 3.3 “驾驶舱”视图：极致的透明度
在TUI或UI界面中，系统会像飞机的驾驶舱一样，实时显示关键信息：
- **当前模型**: `llama3:8b`
- **上下文使用率**: `Token Usage: 4100/8192` (当超过90%时会变色并提示正在压缩)
- **系统状态**: `[正在调用工具: read_file]`

## 4. 核心功能

### 4.1 AI生成团队与SOP (推荐用法)
通过`daip project scaffold`命令或UI界面，用自然语言描述您的目标，系统将自动为您创建AI团队和工作流文件，并请求您的最终确认。

**真实场景示例**:
```bash
# 启动多角色辩论（人力资源政策讨论）
daip debate start "Should we adopt 4-day workweek?" --roles=HR_director,team_lead,employee_rep

# 创建项目维基知识库（市场营销方案）
daip wiki create "Q3 Campaign Strategy" --source=docs/marketing/

# 实时调整执行队列
daip queue list
daip queue reorder 3 1  # 将第3条指令提至首位
daip queue drop 2        # 删除第2条指令
```

### 4.2 内置核心工具
系统内置了强大的文档处理工具，您只需在对话中向AI下达指令即可：
- **论文下载**: “*帮我搜索关于‘强化学习’的最新arXiv论文。*”
- **文档生成与转换**: “*将我们的讨论总结成一份报告，保存为PDF格式。*”

## 5. 高级自定义与安全

### 5.1 自定义AI行为：修改提示词
进入 `prompts/` 文件夹，阅读 `README.md` 后，可直接修改模板文件来精细地调整AI的行为。

### 5.2 自定义AI角色与工具
在 `roles/` 目录下创建`.yaml`文件来定义新角色，并规定它能使用哪些工具。

### 5.3 精细化权限控制
在`config.yaml`中，您可以为高风险工具（特别是`bash`）设置权限，这对于安全至关重要。
```yaml
tool_permissions:
  bash:
    # 允许执行所有git和ls命令
    allow: ["git *", "ls"]
    # 禁止执行rm命令
    deny: ["rm *"]
    # 执行其他所有命令前，弹框询问用户
    default: ask 
```

## 6. 故障排除
- **连接本地LLM失败？** 确认Ollama等服务已在后台运行。
- **文档转换失败？** 确认Pandoc已正确安装。
- **查看日志**: 日志文件位于`logs/`文件夹中。
