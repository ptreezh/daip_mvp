# TUI快捷命令规范

## 1. 概述
本文档详细描述了TUI（文本用户界面）中所有快捷命令的语法、功能和预期行为。

## 2. 快捷命令列表

### 2.1 /pa 命令 - 个人助理
**功能**：启动个人助理执行特定任务
**语法**：`/pa <goal>`
**参数**：
- `goal`：个人助理需要执行的任务目标（必需）
**行为**：
1. 解析命令参数
2. 创建新的个人助理会话
3. 将当前会话压入会话栈
4. 设置新会话为当前活动会话
5. 显示会话创建成功信息

### 2.2 /role 命令 - 角色管理
**功能**：管理AI角色
**语法**：`/role <subcommand> [args]`
**子命令**：

#### 2.2.1 /role add - 创建角色
**语法**：`/role add <name> <persona>`
**参数**：
- `name`：角色名称（必需）
- `persona`：角色描述（必需）
**行为**：
1. 解析角色名称和描述
2. 创建新的角色对象
3. 显示角色创建成功信息

#### 2.2.2 /role view - 查看角色
**语法**：`/role view <role_name>`
**参数**：
- `role_name`：要查看的角色名称（必需）
**行为**：
1. 根据名称查找角色
2. 如果找到，显示角色详细信息（名称、描述、工具列表）
3. 如果未找到，显示错误信息

#### 2.2.3 /role list - 列出角色
**语法**：`/role list`
**行为**：
1. 获取所有可用角色
2. 显示角色列表，包括名称和描述摘要

### 2.3 /0 命令 - 知识库操作
**功能**：搜索或同步知识库
**语法**：`/0 [query]`
**参数**：
- `query`：搜索查询（可选）
**行为**：
1. 如果提供查询参数，执行知识库搜索
2. 如果不提供查询参数，执行知识库同步
3. 显示操作结果

### 2.4 /debate 命令 - 启动辩论
**功能**：启动多智能体辩论
**语法**：`/debate <topic>`
**参数**：
- `topic`：辩论主题（必需）
**行为**：
1. 解析辩论主题
2. 创建新的辩论会话
3. 将当前会话压入会话栈
4. 设置新会话为当前活动会话
5. 显示会话创建成功信息和参与者信息

### 2.5 /v 命令 - 会话搜索
**功能**：搜索会话历史
**语法**：`/v [query]`
**参数**：
- `query`：搜索查询（可选）
**行为**：
1. 如果提供查询参数，按目标或ID搜索会话
2. 如果不提供查询参数，列出所有会话历史

### 2.6 /l 命令 - 会话列表
**功能**：列出所有会话历史
**语法**：`/l`
**行为**：
1. 获取所有会话
2. 显示会话列表，包括ID、目标和状态

### 2.7 /c 命令 - 中断会话
**功能**：中断当前会话并返回父会话
**语法**：`/c`
**行为**：
1. 将当前会话状态设置为失败（中断）
2. 将会话保存到数据库
3. 将当前会话压入会话栈
4. 如果会话栈不为空，弹出父会话并设置为当前会话
5. 如果会话栈为空，清除当前会话
6. 显示操作结果和清除上下文提示

### 2.8 /g 命令 - 继续会话
**功能**：继续当前会话
**语法**：`/g`
**行为**：
1. 检查是否存在当前会话
2. 如果存在，显示会话详细信息
3. 如果不存在，显示错误信息

### 2.9 /p 命令 - 暂停会话
**功能**：暂停当前会话
**语法**：`/p`
**行为**：
1. 检查是否存在当前会话
2. 如果存在，将会话状态更新为观察状态
3. 保存会话到数据库
4. 显示操作结果和会话详细信息
5. 如果不存在，显示错误信息

### 2.10 /t 命令 - 会话树
**功能**：显示会话树结构
**语法**：`/t`
**行为**：
1. 获取所有会话
2. 显示会话树，包括层次结构
3. 标记当前会话和会话栈中的会话

### 2.11 /tc 命令 - 中断并跳转
**功能**：中断当前会话并跳转到指定会话
**语法**：`/tc <index>`
**参数**：
- `index`：会话索引（必需）
**行为**：
1. 解析会话索引
2. 验证索引有效性
3. 将当前会话压入会话栈
4. 显示会话中断信息
5. 跳转到目标会话
6. 显示目标会话信息和继续提示

### 2.12 /tt 命令 - 暂停并跳转
**功能**：暂停当前会话并跳转到指定会话
**语法**：`/tt <index>`
**参数**：
- `index`：会话索引（必需）
**行为**：
1. 解析会话索引
2. 验证索引有效性
3. 将当前会话压入会话栈
4. 显示会话暂停信息
5. 跳转到目标会话
6. 显示目标会话信息和继续提示

### 2.13 ESC键 - 全局中断
**功能**：中断所有会话并返回默认会话
**按键**：`ESC`
**行为**：
1. 清空会话栈
2. 清除当前会话
3. 显示操作结果
4. 显示清除上下文提示

## 3. 错误处理
所有命令都应包含适当的错误处理：
- 参数验证失败时显示错误信息
- 资源不存在时显示错误信息
- 系统错误时显示错误信息

## 4. 用户反馈
所有命令执行后都应提供适当的用户反馈：
- 成功操作显示确认信息
- 失败操作显示错误信息
- 需要用户输入的操作显示提示信息
