# DAIP-LIVE TUI 快捷退出功能测试计划

## 测试目标
验证Ctrl+Q快捷键功能的正确性和稳定性

## 测试环境
- Windows/Linux/macOS操作系统
- Python 3.9+
- Poetry环境
- DAIP-LIVE最新代码

## 测试用例

### 测试用例1: 单次Ctrl+Q退出会话
**前提条件**: TUI已启动，有活动会话
**测试步骤**:
1. 启动TUI应用
2. 开始一个会话（输入任意命令）
3. 按下Ctrl+Q
**预期结果**:
- 当前会话被终止
- 显示"会话已终止。再次按 CTRL+Q 退出应用。"提示
- 状态栏更新为"会话已终止 - 再次按 CTRL+Q 退出应用"
- 执行器被重置

### 测试用例2: 连续Ctrl+Q退出应用
**前提条件**: TUI已启动
**测试步骤**:
1. 启动TUI应用
2. 快速连续按下两次Ctrl+Q（间隔小于2秒）
**预期结果**:
- TUI应用退出
- 无错误信息

### 测试用例3: 超时后单次Ctrl+Q
**前提条件**: TUI已启动
**测试步骤**:
1. 启动TUI应用
2. 按下Ctrl+Q
3. 等待5秒后再次按下Ctrl+Q
**预期结果**:
- 第一次按下：显示会话终止提示
- 第二次按下：显示退出应用提示（因为超时后状态重置）

### 测试用例4: 无活动会话时的Ctrl+Q
**前提条件**: TUI已启动，无活动会话
**测试步骤**:
1. 启动TUI应用（不开始任何会话）
2. 按下Ctrl+Q
**预期结果**:
- 显示"再次按 CTRL+Q 退出应用"提示
- 状态栏更新为"再次按 CTRL+Q 退出应用"

### 测试用例5: 与现有快捷键的兼容性
**前提条件**: TUI已启动
**测试步骤**:
1. 启动TUI应用
2. 测试现有快捷键（Ctrl+E, Ctrl+C等）是否正常工作
3. 测试Ctrl+Q是否正常工作
**预期结果**:
- 所有现有快捷键功能正常
- Ctrl+Q功能正常
- 无冲突
