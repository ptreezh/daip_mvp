# Personal Intelligence Hub - 双入口Lona界面设计方案

## 概述

基于DDD架构设计的Personal Intelligence Hub双入口系统，提供Secretariat（秘书处）和Forum（论坛）两种用户交互模式。本设计方案详细阐述了Lona Web界面的架构、组件设计、交互流程和技术实现。

## 3. 交互设计

### 3.1 用户流程

#### 3.1.1 首次使用流程

```
用户访问 → 入口选择 → 用户配置 → 模式选择 → 功能使用
    ↓         ↓         ↓         ↓         ↓
  首页展示   模式介绍   偏好设置   界面加载   核心功能
```

#### 3.1.2 Secretariat模式流程

```
任务提交 → 意图分析 → 角色匹配 → 任务执行 → 结果反馈
    ↓         ↓         ↓         ↓         ↓
  用户输入   智能分析   专家选择   工作流运行   质量报告
```

#### 3.1.3 Forum模式流程

```
主题设定 → 角色选择 → 辩论开始 → 实时交互 → 共识计算
    ↓         ↓         ↓         ↓         ↓
  问题定义   专家邀请   多角讨论   动态更新   结果汇总
```

class WebSocketMessageType(Enum):

### 4.3 状态管理

```python
# 状态枚举
class UIState(Enum):
    IDLE = "idle"
    PROCESSING = "processing"
    THINKING = "thinking"
    DEBATING = "debating"
    CONSENSUS = "consensus"

# 组件状态管理
class ComponentState:
    def __init__(self):
        self.current_state = UIState.IDLE
        self.state_history = []
    
    def transition_to(self, new_state: UIState):
        """状态转换"""
        self.state_history.append(self.current_state)
        self.current_state = new_state
```
