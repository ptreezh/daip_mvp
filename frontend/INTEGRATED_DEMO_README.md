# DAIP-LIVE 集成演示系统

## 概述

DAIP-LIVE集成演示系统是一个真实的、完全透明的AI协作演示平台，展示了基于制度原语的集体智慧涌现能力。

## 🎯 核心特性

### ✅ 已完成的集成功能

1. **真实LLM调用**
   - 支持Ollama本地模型
   - 支持OpenAI API
   - 实时显示调用过程和性能指标
   - 完整的调用审计和验证

2. **真实角色库集成**
   - 从roles/目录加载真实角色定义
   - 展示角色认知差异和专业特征
   - 支持角色间的真实交互和辩论

3. **真实工作流执行**
   - 批判性审查工作流
   - 多视角综合工作流
   - 共识计算算法
   - 涌现洞察检测

4. **统一前端界面**
   - 聊天界面 (ChatInterface)
   - 透明度监控 (TransparencyMonitor)
   - Wiki知识库 (WikiPanel)
   - 任务管理 (TaskPanel)

5. **组件间数据流**
   - 实时状态同步
   - 跨组件通信
   - 事件驱动更新
   - WebSocket实时通信

## 🚀 快速启动

### 1. 环境准备

```bash
# 安装Python依赖
pip install -r requirements.txt

# 启动Ollama服务（如果使用本地模型）
ollama serve

# 拉取所需模型
ollama pull llama3:instruct
```

### 2. 启动演示系统

```bash
# 使用启动脚本（推荐）
python start_integrated_demo.py

# 或直接运行应用
python integrated_demo_app.py
```

### 3. 访问演示

打开浏览器访问: http://localhost:8080

## 🎮 使用指南

### 基本操作

1. **选择演示场景**
   - 在控制面板选择预设场景
   - 或创建自定义场景

2. **开始演示**
   - 点击"开始真实演示"按钮
   - 系统会加载相应的角色和工作流

3. **输入问题**
   - 在聊天界面输入要分析的问题
   - 系统会自动触发相应的工作流

4. **观察过程**
   - 透明度监控显示实时执行状态
   - Wiki面板显示知识更新
   - 任务面板显示任务进度

### 特殊命令

- `/consensus now` - 触发共识计算
- `/status` - 查看系统状态
- `/help` - 显示帮助信息
- `/clear` - 清空聊天历史

## 🔧 配置选项

### LLM服务配置

```python
# 在 integrated_demo_app.py 中修改
llm_config = {
    "primary": "ollama",  # 主要LLM服务
    "fallback": "openai", # 备用服务
    "ollama_host": "http://localhost:11434",
    "openai_api_key": "your-api-key"
}
```

### 演示场景配置

```python
# 添加自定义场景
custom_scenario = {
    "name": "自定义场景名称",
    "description": "场景描述",
    "duration": "预计时长",
    "roles": ["角色1", "角色2"],
    "workflows": ["工作流1", "工作流2"]
}
```

## 📊 性能指标

### 系统要求
- **内存**: 最少8GB，推荐16GB
- **CPU**: 4核心以上
- **网络**: 稳定的互联网连接（如使用云端LLM）
- **存储**: 至少2GB可用空间

### 性能基准
- **LLM响应时间**: < 30秒
- **角色加载时间**: < 5秒
- **工作流执行时间**: < 2分钟
- **界面响应时间**: < 1秒

## 🐛 故障排除

### 常见问题

1. **Ollama连接失败**
   ```bash
   # 检查Ollama服务状态
   curl http://localhost:11434/api/tags
   
   # 重启Ollama服务
   ollama serve
   ```

2. **角色加载失败**
   - 检查roles/目录是否存在
   - 验证JSON文件格式是否正确

3. **WebSocket连接问题**
   - 检查防火墙设置
   - 确认端口8080未被占用

4. **内存不足**
   - 关闭其他应用程序
   - 考虑使用更小的模型

### 日志查看

```bash
# 查看应用日志
tail -f logs/integrated_demo.log

# 查看错误日志
grep ERROR logs/integrated_demo.log
```
