# AI-辅助的项目生命周期实践

本指南将AI融入项目的各个阶段，作为智能助手和代码生成引擎：

### 1. 深度需求工程与系统架构 (AI辅助)
*   **目标：** 通过AI辅助生成场景故事、用户画像、初步测试用例、验收标准和非功能性需求（NFRs），并提供初步系统架构建议。
*   **AI职责：** 从非结构化输入中提炼、结构化、量化需求，并基于已知模式提供架构蓝图。

### 2. API优先与后端开发 (AI生成)
*   **目标：** 快速定义API契约，并生成符合规范的后端服务骨架和核心业务逻辑。
*   **AI职责：** 根据业务需求和架构建议，生成符合OpenAPI/Swagger规范的API定义，以及指定语言/框架的后端服务代码。

### 3. 前端与用户体验中心设计 (AI辅助)
*   **目标：** 基于API契约和用户体验要求，快速生成前端UI组件和页面布局。
*   **AI职责：** 生成指定前端框架的UI组件代码，包括结构、样式和基本交互逻辑，并与后端API真实对齐。

### 4. 综合测试与CI/CD (AI增强)
*   **目标：** 实现全面的自动化测试（单元、集成、端到端、AI模型鲁棒性），并构建高效的CI/CD流水线。
*   **AI职责：**
    *   **单元测试生成：** 为指定函数/类生成高质量单元测试用例，**严格遵循反冗余原则**。
    *   **集成/端到端测试生成：** 生成调用真实系统接口的集成测试。
    *   **CI/CD脚本生成：** 辅助编写部署脚本、自动化测试触发规则。

### 5. 部署、维护与持续改进 (AI监控与分析)
*   **目标：** 实现系统上线后的持续监控、问题诊断和性能优化。
*   **AI职责：** 识别关键监控指标、生成告警规则，辅助进行根本原因分析，并提出优化建议。

### 6. 代码审查与质量控制 (AI辅助)
*   **目标：** 确保代码质量、符合编码规范，并严格执行反冗余原则。
*   **AI职责：** 自动化执行代码质量、规范审查，尤其强调**识别和标记所有桩子函数、空函数、桩子类、空类以及模拟核心业务逻辑的Mock类**。
