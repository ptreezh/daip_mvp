- `ChatViewModel`: Manages conversation flows and messaging
- `RoleViewModel`: Handles role selection and management
- `SessionViewModel`: Manages session lifecycle and persistence
- `DebateViewModel`: Coordinates multi-agent debate functionality
- `KnowledgeViewModel`: Handles knowledge base search and management

### **View Layer**:
- `MainWindow`: Main application frame with navigation
- `ChatView`: Real-time messaging interface
- `RoleView`: Role selection and configuration
- `SessionView`: Session management interface
- `DebateView`: Multi-agent debate interface
- `KnowledgeView`: Knowledge base search interface

### **Platform Layer**:
- `WindowsAdapter`: Windows-specific functionality

- `PlatformAdapter`: Base abstraction for cross-platform support

### **Theme Layer**:

- `APIClient`: FastAPI backend communication
- `InteractionLayer`: Abstract interface for all services
