# Personal Intelligence Hub

**基于制度原语的集体智慧涌现平台**

Personal Intelligence Hub是一个统一的对话界面，用户通过与单一的智能个人助手交互，该助手将自然语言指令转换为强大的底层"社会制度"(工作流)的执行，使复杂的AI协作变得直观和易于访问。

## 🌟 核心特性

### 🎯 统一对话界面
- **单一入口点**: 用户只需与一个智能助手交互
- **自然语言处理**: 直接用自然语言描述需求，系统自动理解意图
- **实时对话**: 支持持续的对话交互，保持上下文连贯性

### 🤖 智能代理协作
- **自动团队组建**: 基于任务需求自动选择最适合的AI专家团队
- **认知多样性**: 确保团队具备不同的认知框架和推理方式
- **专业角色**: 支持批判性分析、多角度讨论、专业评估等多种角色

### 🔍 完全透明监控
- **实时状态显示**: 所有系统内部过程对用户完全可见
- **代理活动跟踪**: 实时显示每个AI代理的当前状态和任务
- **LLM调用监控**: 详细记录所有大语言模型调用和Token消耗
- **性能指标**: 实时显示响应时间、成功率等关键指标

### 📚 知识管理集成
- **动态Wiki**: 自动更新的知识库，记录讨论中产生的事实和洞察
- **记忆系统**: 智能的对话记忆管理，支持长期上下文保持
- **版本控制**: 知识的版本历史和质量评分

### ⚡ 高级功能
- **自然语言工作流编译**: 用自然语言描述复杂的协作流程
- **共识计算**: 实时计算多代理讨论的共识状态
- **上下文优化**: 智能的提示优化和上下文协作创建

## 🏗️ 技术架构

### 前端技术栈
- **Lona Web Framework**: 统一的Python前后端框架
- **组件化设计**: 模块化的UI组件，易于维护和扩展
- **实时WebSocket**: 支持实时状态更新和消息推送
- **响应式布局**: 适配不同设备和屏幕尺寸

### 后端集成
- **DAIP-LIVE集成**: 基于现有的强大后端服务
- **微服务架构**: 松耦合的服务设计，支持独立扩展
- **异步处理**: 高性能的异步消息处理
- **容错机制**: 优雅降级和错误恢复

## 🚀 快速开始

### 环境要求
- Python 3.8+
- DAIP-LIVE后端服务 (可选，支持降级模式)

### 安装依赖
```bash
cd personal_intelligence_hub
pip install -r requirements.txt
```

### 启动应用
```bash
# 方式1: 使用启动脚本
python run_hub.py

# 方式2: 直接运行主应用
python main_app.py

# 方式3: 运行功能演示
python demo_script.py
```

### 访问应用
- 主界面: http://localhost:8086/hub
- 首页: http://localhost:8086/

## 💡 使用指南

### 基本对话
1. 在聊天界面输入自然语言请求
2. 系统自动分析意图并组建专家团队
3. 确认团队配置后开始分析
4. 实时查看分析过程和结果

### 特殊命令
- `/help` - 显示帮助信息
- `/status` - 查看系统状态
- `/consensus now` - 计算当前讨论的共识
- `/clear` - 清除当前会话

### 示例对话
```
用户: 我需要对人工智能的安全风险进行可靠的分析

助手: 我理解您想要基于关键词的本地分析：建议使用批判性审查工作流

我将让Critic-AI, Analyst-AI, Validator-AI使用critical_review流程分析。继续吗？

团队组成：Critic-AI, Analyst-AI, Validator-AI
多样性评分：0.75
置信度：0.70

如果您确认，我将启动工作流开始分析。您也可以输入 /consensus now 来查看当前讨论的共识状态。
```

## 🛠️ 开发指南

### 项目结构
```
personal_intelligence_hub/
├── components/          # UI组件
│   ├── chat_interface.py
│   ├── transparency_monitor.py
│   ├── wiki_panel.py
│   └── task_panel.py
├── services/           # 业务服务
│   ├── personal_assistant.py
│   ├── backend_integration.py
│   └── websocket_manager.py
├── models/            # 数据模型
│   ├── chat_models.py
│   └── transparency_models.py
├── static/            # 静态资源
│   └── css/
│       └── main.css
├── tests/             # 测试文件
├── main_app.py        # 主应用入口
├── run_hub.py         # 启动脚本
├── demo_script.py     # 演示脚本
└── requirements.txt   # 依赖列表
```

### 添加新组件
1. 在`components/`目录创建新的组件文件
2. 继承`lona.Component`基类
3. 实现`render()`方法返回HTML结构
4. 在主应用中导入和使用

### 扩展后端集成
1. 在`services/backend_integration.py`中添加新的API方法
2. 实现错误处理和降级逻辑
3. 在相关组件中调用新的服务方法

### 自定义样式
1. 编辑`static/css/main.css`文件
2. 使用CSS类名对应组件的`_class`属性
3. 支持响应式设计和动画效果
