## 使用示例

```python
# 创建调度器
config = DispatcherConfig(
    default_timeout=30.0,
    max_concurrent_requests=100,
    fallback_enabled=True
)
dispatcher = UnifiedConsensusDispatcher(config)

# 管理器
manager = DispatcherManager(dispatcher)
metrics_collector = MetricsCollector(dispatcher)
config_manager = ConfigurationManager(dispatcher)

# 注册算法
algorithm = MyConsensusAlgorithm("my_algo")
manager.register_algorithm("my_algo", algorithm)

# 执行共识计算
request = ConsensusRequest(inputs=[...])
response = await dispatcher.calculate_consensus(request)

# 获取指标
metrics = metrics_collector.get_metrics()

# 更新配置
config_manager.update_config({
    "default_timeout": 60.0,
    "max_concurrent_requests": 200
})
```

## 架构集成

```
UnifiedConsensusDispatcher
```

```
ConsensusRequest → 算法选择 → 算法执行 → 降级处理 → ConsensusResponse
                     ↓           ↓           ↓
                  指标收集 → 状态更新 → 监控报告
```
