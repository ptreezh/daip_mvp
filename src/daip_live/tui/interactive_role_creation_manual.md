# TUI交互式AI角色创建功能 - 用户使用手册

## 1. 功能概述

交互式AI角色创建功能允许用户通过自然语言描述来创建专业化的AI角色。系统将使用AI模型分析用户的需求，生成角色配置，并允许用户确认或自定义角色。

## 2. 命令说明

### 2.1 基础命令

- `/role list` - 列出所有已存在的角色
- `/role show <角色名>` - 显示特定角色的详细信息
- `/role switch <角色名>` - 切换到指定角色
- `/role create <描述>` - 根据描述创建角色
- `/role interactive <描述>` - 交互式角色创建（推荐）
- `/role confirm <会话ID>` - 确认角色创建

### 2.2 交互式创建流程

1. **启动创建流程**：
   ```
   /role interactive <角色描述>
   ```
   例如：`/role interactive 数据科学家，擅长机器学习`

2. **AI生成建议**：
   系统将生成角色建议，包括名称、人设和工具

3. **确认或修改**：
   - 使用 `/role confirm <会话ID>` 确认使用AI生成的配置
   - 或自行修改角色配置后再次确认

## 3. 示例用法

### 3.1 创建数据分析师角色
```
/role interactive 数据分析师，擅长数据可视化和统计分析
```

### 3.2 创建法律顾问角色
```
/role interactive 企业法律顾问，专精合同审查和合规
```

### 3.3 创建编程导师角色
```
/role interactive Python编程导师，擅长Web开发教学
```

## 4. 配置说明

生成的角色将包含以下配置：

- **角色名称**：角色的唯一标识
- **角色人设**：角色的行为和语言风格描述
- **工具列表**：角色可使用的工具和能力

## 5. 注意事项

- 创建角色需要AI模型的响应，请确保系统连接正常
- 角色创建后会保存到roles目录中
- 可以随时使用`/role list`查看已创建的角色
